MGA DISCOVERY - PACOTE PREPARADO PARA WINDOWS
==============================================

1) Extraia a pasta MGA_Discovery_PRONTO inteira.
2) Instale Python 3.11+ (marque "Add Python to PATH"):
   https://www.python.org/downloads/
3) Instale Node.js LTS 20+ (npm ja vem junto):
   https://nodejs.org/en/download
4) Conecte a internet na primeira execucao.
5) Execute run.bat com dois cliques.

O BAT cria o ambiente virtual, instala as dependencias Python, instala
as dependencias React, compila o frontend e roda o diagnostico.

IMPORTANTE SOBRE A BASE:
O Excel enviado (MGA_Resultados_Etapa3.xlsx) contem as abas:
Ablacao, Sensibilidade, Consultas_Top5 e Consistencia.
Ele e a planilha de RESULTADOS, nao a base de dados dos jogos.

Para habilitar catalogo, comparacoes e recomendacoes, o projeto tambem
precisa da planilha original dos 66 jogos, com uma aba chamada Base_Jogos.
Coloque essa planilha em:
backend\data\

Colunas esperadas pelo algoritmo:
jogo, ano, diretor, quantidade_premios, vendas_milhoes,
pais_maior_vendas, plataforma, genero,
jogadores_concluiram_hltb, nota_publico_metacritic,
nota_critica_metacritic.

O sistema nao inventa nem reconstrui os dados ausentes. Sem essa planilha,
o diagnostico interrompe a inicializacao e explica o que falta.

Se o BAT parar, nao feche a janela: copie a mensagem de erro.
